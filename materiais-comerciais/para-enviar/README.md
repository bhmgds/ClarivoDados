# Materiais para enviar ao cliente — Clarivo Dados

Esta pasta reúne modelos organizados por etapa comercial; **não envie a pasta inteira ao cliente**. Faça uma cópia dos arquivos que vai personalizar para uma pasta interna daquele cliente. Os PDFs não são formulários interativos.

## Conteúdo

1. [`01-apresentacao/`](./01-apresentacao/) — apresentação comercial para uma conversa inicial. Preencha os contatos antes de compartilhar.
2. [`02-briefing/`](./02-briefing/) — perguntas curtas para entender a necessidade sem solicitar dados reais.
3. [`03-proposta/`](./03-proposta/) — proposta comercial sem notas internas de precificação.
4. [`04-contratacao/`](./04-contratacao/) — minuta de contrato e anexo, somente após personalização e revisão jurídica.
5. [`05-guia-de-envio.md`](./05-guia-de-envio.md) e [`05-guia-de-envio.pdf`](./05-guia-de-envio.pdf) — guia de uso interno; não enviar ao cliente.

## Atalho

- Primeira conversa: apresentação, se ajudar a explicar o serviço.
- Depois da conversa: briefing ou pedido de cabeçalho/amostra fictícia.
- Escopo estimado: proposta preenchida.
- Proposta aprovada: contrato revisado e assinatura.
- Dados reais: só após formalização e confirmação do canal.

Não envie o kit completo em ZIP nem os modelos em branco. Veja o guia antes de cada etapa.
