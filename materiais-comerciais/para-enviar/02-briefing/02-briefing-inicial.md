Este briefing serve para entender a necessidade e estimar o escopo. **Não envie a base real nesta etapa.** Se possível, compartilhe somente os nomes das colunas ou uma amostra fictícia, sem dados pessoais, confidenciais ou credenciais.

## 1. Objetivo

- Qual pergunta de negócio você quer responder?
- Que decisão pretende apoiar com essa análise?
- Qual área ou processo está envolvido?
- Qual período deve ser analisado?
- Existe uma data importante para a entrega?

## 2. Dados disponíveis

- Em quais arquivos ou sistemas estão as informações?
- Quem consegue exportar os arquivos?
- Quais formatos estão disponíveis (Excel, CSV ou outro)?
- Qual é o volume aproximado (quantidade de arquivos e linhas)?
- Quais campos parecem necessários para responder à pergunta?
- Os arquivos têm identificadores comuns para relacionar os dados?
- Há uma definição importante a combinar, como cancelamentos, devoluções, descontos ou datas?

## 3. Entrega e validação

- O que seria mais útil: diagnóstico da base, relatório PDF ou dashboard Power BI local?
- Quais indicadores ou recortes são prioritários?
- Quem validará as definições e os totais?
- Quem precisa receber a entrega?
- Para um dashboard local, os destinatários poderão ver todos os registros importados?

## 4. Cuidados antes de compartilhar exemplos

- Não envie senha, credencial, acesso remoto ou exportação completa para orçamento.
- Não inclua nomes, contatos, documentos, prontuários ou outros dados pessoais/sensíveis em uma amostra.
- Prefira cabeçalhos das colunas ou dados sintéticos que preservem apenas a estrutura.
- Se for necessário analisar dados reais, finalidade, campos, destinatários, contrato e canal serão combinados antes do envio.

**Próximo passo:** após entendermos a pergunta e a estrutura dos dados, a Clarivo confirma o escopo, o prazo e o investimento em uma proposta.
