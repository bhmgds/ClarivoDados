COMECE POR AQUI

Como usar

Um controle leve para tocar a Clarivo sem contratar uma plataforma.

01

Cadastre um contato

Registre empresa, pessoa de contato, origem, etapa comercial e a próxima data de acompanhamento.

02

Acompanhe a proposta

Associe uma proposta ao contato. Anote valor, validade, status e o caminho do arquivo da proposta preenchida.

03

Organize a execução

Quando fechar, crie um projeto, acompanhe prazo, saldo e caminho dos documentos. Use tarefas para follow-ups.

04

Faça backup

Baixe um backup JSON periodicamente e antes de trocar de navegador ou computador. Restaurar substitui os registros atuais.

Estrutura de pastas sugerida

Guarde os documentos do trabalho em pastas locais separadas por cliente e projeto. No campo “Pasta dos documentos”, registre apenas o caminho da pasta — não anexe bases nem arquivos pessoais ao sistema.

Cuidados importantes

  • O sistema funciona localmente e não envia dados para serviços externos. Os dados ficam no armazenamento deste navegador e perfil do computador.
  • O armazenamento do navegador não é criptografado pelo aplicativo. Use um computador com conta protegida e criptografia de disco; não use em computador compartilhado.
  • E-mail e telefone de trabalho também podem ser dados pessoais: registre só o necessário. Não guarde CPF/CNPJ de pessoas, dados bancários, senhas, dados sensíveis ou arquivos de clientes aqui.
  • Mantenha apenas dados comerciais básicos e caminhos de documentos.
  • O backup JSON é legível e não criptografado. Proteja-o como informação confidencial e evite colocá-lo em pasta sincronizada ou compartilhada sem avaliar o acesso.
  • Este é um controle operacional simples, não substitui contrato, armazenamento seguro de arquivos, sistema contábil ou orientação jurídica.
