# Clarivo Dados

Projeto de estruturação de um serviço independente de análise de dados para
pequenas empresas. A proposta é transformar planilhas e arquivos exportados
pelos próprios clientes em informações mais claras para apoiar decisões de
gestão.

## O que o projeto propõe

- **Raio-X de dados:** avaliar se os arquivos disponíveis respondem às perguntas
  do negócio.
- **Relatórios gerenciais em PDF:** organizar indicadores, comparações e pontos
  de atenção em uma entrega de escopo definido.
- **Dashboards locais em Power BI:** alternativa interativa para consulta no
  Power BI Desktop, em ambiente compatível.
- **Nova edição mensal do relatório:** opção contratada à parte, baseada em
  novos arquivos enviados pelo cliente; não é atualização automática nem suporte
  contínuo.

O escopo inicial não inclui automação, integração com sistemas, hospedagem,
publicação online ou atualização agendada. Os documentos são um plano de
negócio e materiais de preparação; preços e metas neles descritos são hipóteses
comerciais, não garantias de resultado. Os exemplos de portfólio usam dados
fictícios.

## Visualizar a landing page

Abra `landing/index.html` diretamente em um navegador. A página usa o arquivo
de estilos local `landing/style.css` e não requer instalação ou compilação.

## Cuidados com dados

Os casos demonstrativos devem permanecer fictícios. Antes de iniciar qualquer
projeto com dados reais, é necessário definir finalidade, escopo, canal de envio,
controles de acesso e prazo de retenção com o cliente. A documentação apresenta
orientações de preparação, não certifica conformidade legal nem afirma que
controles operacionais já estejam implementados.
